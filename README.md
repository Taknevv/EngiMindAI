# EngiMind AI

An engineering-focused Retrieval-Augmented Generation (RAG)
assistant for robotics, SLAM, localization, navigation and
control systems.

## Project Goals

- Process engineering PDF documents.
- Extract and clean document text.
- Generate semantic embeddings.
- Store and retrieve knowledge using a vector database.
- Generate grounded AI answers with source references.
- Evaluate retrieval and answer quality.
- Deploy a public demonstration.

## Technology Stack

- Python 3.12
- Sentence Transformers
- ChromaDB
- Streamlit
- Hosted LLM API
- PyMuPDF
- Git and GitHub
